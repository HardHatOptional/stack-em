# Stack 'Em

A fun stack-based strategy game.

**Play here:** [https://stack-em.vercel.app](https://stack-em.vercel.app) (after deployment)

### How to Play
- Click one of your stacks, then click a valid destination.
- Higher full stacks can capture lower enemy stacks.
- Split stacks by moving only part of your coins.
- Last player with coins wins.
